UUID Generator

A UUID (Universally Unique Identifier) is a 128-bit ID printed as 32 hexadecimal digits in an 8-4-4-4-12 pattern — the standard way to give database rows, API resources and files an ID that never collides. This generator builds v4 (random) or v7 (time-ordered, RFC 9562) UUIDs entirely in your browser with the Web Crypto API, one at a time or up to 100 in bulk, and can also inspect any UUID you paste: its version, variant, and — for v1, v6 and v7 — the time it was created.

How to use the UUID Generator

  1. Choose v4 (random) or v7 (time-ordered).
  2. Set how many UUIDs you need (1–100) and pick an output format.
  3. Select “Generate UUIDs”, then copy them all or download them as a .txt file. To inspect an existing UUID, paste it below and select “Inspect”.

Formula and method

A v4 UUID carries 122 random bits: with about 5.3 × 10³⁶ possible values, two independently generated v4 UUIDs colliding is practically impossible. A v7 UUID starts with a 48-bit Unix timestamp in milliseconds, so newer IDs sort after older ones — useful for database primary keys — followed by 62 random bits. Both set the version nibble (4 or 7) and the variant bits (10xx, the RFC 4122 variant) as the standards require.

Frequently asked questions

Is a generated UUID sent to a server?

No. Generation uses crypto.getRandomValues in your browser; UUIDs never leave your device and nothing is stored.

v4 or v7 — which should I use?

v4 (random) is the safe default for general-purpose IDs. v7 is better for database primary keys because its timestamp prefix keeps new rows sorting after old ones, which keeps indexes compact. Either is fine for one-off IDs.

Can two generated UUIDs ever be the same?

In practice, no. A v4 UUID has 122 random bits, so you would need to generate roughly 2.7 quintillion of them before the odds of a single duplicate reach 50%.

What does the inspector show for a v4 UUID?

Its version (4) and variant (RFC 4122). v4 UUIDs carry no timestamp, so no creation time is shown — only v1, v6 and v7 encode when they were made.
