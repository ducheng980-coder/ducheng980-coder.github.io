Password Generator

A strong password is long and random, not a word with a number tacked on. This generator builds one for you in your browser using cryptographically secure randomness (crypto.getRandomValues), with your choice of length and character types. Nothing is sent to a server, so the password exists only on your device until you copy it.

How to use the Password Generator

  1. Choose a length — 16 characters or more is a good default.
  2. Tick the character types to include (uppercase, lowercase, digits, symbols).
  3. Select “Generate password”, then copy the result with the copy button.

Formula and method

Entropy measures guessing difficulty: entropy (bits) = length × log₂(pool size). A 16-character password drawn from all four character types (87 characters) has about 103 bits of entropy — an offline attack at 10 billion guesses per second would need on average over ten trillion years to find it. Passwords are generated with the browser’s cryptographically secure random source, never Math.random.

Frequently asked questions

Is the generated password sent to a server?

No. Generation uses crypto.getRandomValues in your browser; the password never leaves your device.

How long should a password be?

At least 12 characters, and 16 or more is better — length matters more than adding symbols. For accounts you care about, use a password manager and give each account its own password.

Why does the tool guarantee one character from each selected type?

Some sites require at least one uppercase letter, digit or symbol. Including one of each by construction keeps the password valid on those sites without weakening the randomness much.

What does “exclude ambiguous characters” do?

It removes characters that are easy to confuse when read aloud or typed — l, o, 1, I, O and 0 — so a password you copy by hand is less likely to be mistyped.
