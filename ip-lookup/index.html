IP Address Lookup

Every device on the internet presents a public IP address, and that address carries rough information about where the connection is and who provides it. This page shows yours as soon as it loads — IP address, country/region, city, ISP, ASN and time zone — using the free ipwho.is service, with ipapi.co as a fallback. You can also type any IPv4 or IPv6 address to look it up the same way, and the page lists what your browser itself reports locally (user agent, language, screen size, time zone) for comparison.

How to use the IP Address Lookup

  1. Open the page — your own public IP details load automatically.
  2. To check another address, type an IPv4 or IPv6 address into the box and select “Look up”.
  3. Select “Show my IP” to return to your own address.

Formula and method

The page asks a third-party IP geolocation API (ipwho.is first, ipapi.co as fallback) about the address; the service matches it against its database of IP allocations and returns the registered country, region, city, ISP, ASN and time zone. Location is approximate — databases usually identify the ISP’s routing point, not a street address — and the address you query is sent to that API so it can answer.

Example

Looking up 8.8.8.8 (a Google public DNS address) reports the United States, Google LLC as the organisation and AS15169 as the ASN. Use the “Load example” button above to try it with the sample inputs.

Frequently asked questions

How accurate is the location?

Country-level results are usually right; city-level results are approximate and can be off by tens of kilometres, because the database locates the ISP’s infrastructure rather than your home. Never treat an IP location as a street address.

Why does the page show a different city from where I live?

Your ISP may route your traffic through a regional hub, and mobile networks often exit in another city entirely. A VPN or proxy replaces your address with its own — the lookup then describes the VPN server, not you.

Is my IP address stored?

Not by this site — the page has no server of its own. Your browser sends the queried address directly to the geolocation API (ipwho.is, or ipapi.co as fallback) over HTTPS, and that service’s own privacy policy applies to the request.

What is an ASN?

An Autonomous System Number identifies the network operator that announces an IP range on the global routing system — for example AS15169 is Google. It is the quickest way to see which organisation an address belongs to.
