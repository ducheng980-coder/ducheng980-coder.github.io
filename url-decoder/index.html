URL Decoder

Percent-encoded URLs are unreadable: %20, %26, %C3%A9 everywhere. Paste one here to decode it back into normal text so you can inspect query parameters, file names and redirects.

Advertisement

How to use the URL Decoder

  1. Paste the encoded text.
  2. Keep “component” mode on for single values; turn it off for whole URLs.
  3. Select “Decode”.

Formula and method

Each %XX hex pair is converted back to its byte, and the byte sequence is decoded as UTF-8. An invalid sequence (such as %ZZ or a stray %) is reported instead of guessed.

Example

fish%20%26%20chips decodes to “fish & chips”. Use the “Load example” button above to try it with the sample inputs.

Frequently asked questions

Why did I get an error?

The input likely contains an incomplete escape (a trailing %) or hex digits outside 0–9 A–F.

Does it decode + as a space?

decodeURIComponent does not turn + into a space. If the string came from a form submission, replace + with a space first.
